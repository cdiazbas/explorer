# 0004. La aplicación, en inglés; las notas, en español

- **Estado:** Vigente
- **Fecha:** 2026-09-28
- **Decide:** el usuario

## Decisión

**En inglés:** todo lo que es aplicación.
- el código: nombres, comentarios y docstrings;
- lo que ve el usuario: la interfaz, los mensajes, `--help`, `doctor`, los registros;
- los informes JSON, las pruebas y los scripts;
- los mensajes de commit.

**En español:** los ficheros Markdown del proyecto (plan, hoja de ruta, decisiones, diario,
traspaso, ideas) y las conversaciones.

## Consecuencias

- El `README.md`, si algún día se publica para otros, necesitará una versión en inglés;
  mientras tanto sigue la regla de los Markdown.
- Las revisiones de código incluyen el idioma: un texto de interfaz en español es un fallo.
